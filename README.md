# movie whisperer

Podpowiadacz filmu: rekomendacje na podstawie preferencji
i aktualnego nastroju użytkownika, z agentem AI wyjaśniającym dopasowanie.

Projekt zespołowy, Inżynieria Oprogramowania 2026/27, Politechnika Śląska.

## Zespół
Robert Adamek, Patrycja Kustra, Albert Nakielski, Bartosz Orawiec

## Status
Etap: analiza tematu i dobór narzędzi. Kod aplikacji jest w przygotowaniu.

## Zasoby projektu
- Repozytorium: (ten link)
- Zarządzanie zadaniami: Jira
- Komunikacja: Discord

## Planowane elementy
- kwestionariusz preferencji i nastroju
- rekomendacje na podstawie danych o filmach
- agent AI uzasadniający dopasowanie i wskazujący platformy

## Źródła danych i atrybucja
Ten produkt korzysta z API TMDB, ale nie jest przez TMDB popierany
ani certyfikowany. Dane o dostępności na platformach: JustWatch.
Szczegóły w docs/zrodla.md.
